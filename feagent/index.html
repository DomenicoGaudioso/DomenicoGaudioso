Perché feagent?

Un framework FEM dedicato all'analisi strutturale che vive nel terminale e parla con l'intelligenza artificiale.

🔺

FEM Strutturale

Solver agli elementi finiti per analisi strutturale: statica lineare e non lineare, dinamica e modale.

🤖

AI-Assisted Mesh

Genera geometrie e mesh da descrizioni testuali. Ottimizza la risoluzione automaticamente.

⚡

Lightning Solver

Parallelizzazione nativa, sparse matrix solver e cache dei risultati per iterazioni rapide.

🧮

Analisi Complete

Statica, dinamica, modale, buckling e fatica: combinazioni di carico e verifiche SLU/SLE.

🛡️

Local-First

Tutto in locale. Nessun cloud obbligatorio. I tuoi modelli e i tuoi dati restano tuoi.

📦

Export Universale

VTK, STL, STEP, MED, CGNS, ENSIGHT. Compatibile con Paraview, Salome, FreeCAD.

Installazione

Pronto in meno di un minuto. Un binario, zero dipendenze esterne.

bash 
# Installa feagent globalmente
npm install -g feagent

# Autenticati con la tua license key (richiedila contattandoci)
feagent auth --key YOUR_LICENSE_KEY

# Inizializza un progetto FEM
feagent init bridge-analysis

# Genera geometria con AI
feagent ai-generate --prompt "trave a campata singola 30m, carico 50kN"

# Mesh, materiali e solve
feagent mesh --resolution fine
feagent material --type steel --young 210e9
feagent solve --load 50000 --boundary fixed

# Post-processa ed esporta
feagent post --stress --deformation
feagent export --format vtk --output results/

ℹ️ L'utilizzo di feagent richiede una license key. Contattaci per ottenerla.
